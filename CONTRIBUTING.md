# Contributing

Thanks for helping. Issues and pull requests are welcome.

1. Fork and clone the repo. You need Node 18 or newer; there is nothing to install.
2. Make your change. If it changes how something works, update its page in `docs/wiki/`.
3. Run `npm test` and `node bin/hypatia.js check`. Both must pass.
4. Open a pull request that says what changed, why, and how to test it.

Bugs and ideas: [open an issue](https://github.com/maxhawksby/hypatia/issues). How the code fits together: [the wiki](https://maxhawksby.github.io/hypatia/) and [AGENTS.md](AGENTS.md).
